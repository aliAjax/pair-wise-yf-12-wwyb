# 油站网点地图管理

- 行业：石油
- 技术栈：Vue3、Vite、TypeScript、Pinia
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

纯前端最小闭环：数据保存在浏览器 localStorage，地图为页面内自绘的 100km × 100km 本地网格（SVG 点选），
不接后台，也不依赖任何外部地图服务。

## 业务代码分三份

| 文件 | 职责 |
| --- | --- |
| `src/biz/stationRules.ts` | **判定层**：告急线（库存 < 8000L）、同区域按库存从低到高编号（如 东区-01）、区域筛选、调度统计（停业不计）、表单校验（必须先选坐标） |
| `src/biz/stationStore.ts` | **存档层**：Pinia store + localStorage 读写；旧记录（旧字段名 / 缺坐标）读取时统一迁移，缺坐标的 `coord` 置空留档 |
| `src/App.vue` + `src/styles.css` | **页面层**：地图点选、新增 / 编辑表单、区域标签页、油站列表与顶部统计 |

## 关键规则

1. 新增油站：先在地图上点选坐标，再保存名称、区域、库存、负责人；未选坐标无法保存。
2. 同一区域内点位按库存从低到高编号；缺坐标的留档记录不落图、不占号。
3. 库存不足 8000 升自动标为「告急」。
4. 列表切换区域后，地图点位、顶部统计、区域计数只看该区域的油站。
5. 油站停业后点位仍保留在地图上可查看，但从在营数、告急数、调度总库存中退出；可恢复营业。
6. 缺坐标的旧记录正常留档显示，编辑时必须先在地图上补选位置才能保存。
