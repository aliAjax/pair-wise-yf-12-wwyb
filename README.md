# 油站网点地图管理

- 行业：石油
- 技术栈：Vue3、Vite、TypeScript、Pinia、Leaflet
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

纯前端最小闭环，数据保存在浏览器 localStorage，不接后台、不加载任何在线地图瓦片
（Leaflet 底图为本地 Canvas 绘制的经纬网，断网可用）。

## 业务规则

- 新增油站：先在地图点击点选坐标，再保存名称、区域、库存（升）、负责人；未点坐标不能保存。
- 区域编号：同一区域的点位按库存从低到高编号（同库存按名称稳定排序）。
- 库存告急：库存不足 8000 升的在营站点自动标红告急。
- 区域切换：列表切换到某区域后，地图点位与顶部统计（调度油站数、告急数、库存合计）只统计该批油站。
- 停业：停业站点位仍在地图可查看（灰色），但退出调度统计；可恢复营业。
- 旧记录：缺坐标的历史记录自动留档（单独区域展示，不编号、不进地图、不参与统计），
  编辑保存前必须在地图补齐位置，保存后自动解除留档。

## 代码结构（判定 / 存档 / 页面 三份业务代码）

- `src/business/rules.ts` —— 判定层（纯函数）：告急阈值、区域编号、调度统计口径、坐标校验。
- `src/business/archive.ts` —— 存档层（Pinia + localStorage）：记录载入、新增、编辑、停业、旧档标记。
- `src/App.vue` + `src/components/StationMap.vue` —— 页面层：区域过滤、统计卡、表单、列表、地图点选。
